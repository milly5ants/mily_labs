Meu primeiro projeto "de verdade" fora dos exercícios do curso: um Todo List bem simples, feito para praticar lógica de programação e, de quebra, me ajudar a organizar a rotina de estudos.

## O objetivo

Nada de frameworks complicados. Só queria treinar:

1. Estrutura de dados básica para guardar as tarefas
2. Funções para adicionar, concluir e remover itens
3. Persistência simples dos dados

## O que ficou pronto

O projeto ainda é bem inicial, mas já permite:

- adicionar uma nova tarefa;
- marcar como concluída;
- remover uma tarefa da lista;
- ver o total de tarefas pendentes.

## O que aprendi

Fazer algo pequeno de ponta a ponta ensina muito mais do que eu imaginava — desde nomear variáveis de um jeito que faça sentido até pensar em casos que eu não tinha previsto (tipo: e se a lista estiver vazia?).

Nos próximos posts pretendo evoluir esse projeto com uma interface melhor e, quem sabe, salvar as tarefas em um arquivo.
