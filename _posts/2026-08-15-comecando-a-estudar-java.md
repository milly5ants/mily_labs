Depois de meses só olhando para o Java de longe, decidi que era hora de parar de enrolar e começar de verdade. Este post é basicamente um diário dos meus primeiros dias com a linguagem.

## Por que Java?

Escolhi Java porque quero entender melhor backend e arquitetura orientada a objetos, e porque é a linguagem mais usada nas vagas que tenho visto por aqui. Nada muito filosófico — é sobre construir uma base sólida.

## O que já aprendi

- Diferença entre `class` e `interface`
- Como funciona o `main` e o ciclo de compilação com a JVM
- Tipagem estática e por que isso me deixou mais confiante lendo código de outras pessoas

```java
public class OiJaja {
    public static void main(String[] args) {
        System.out.println("Oi, eu sou a Jaja 👋");
    }
}
```

## Próximos passos

A ideia é seguir estudando fundamentos por mais uma ou duas semanas antes de partir para Spring Boot. Vou documentando cada etapa por aqui, então se você também está começando, talvez a gente aprenda junto.
